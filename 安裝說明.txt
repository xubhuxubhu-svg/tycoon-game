製作大亨　第 1 系列「飲食與料理」完整版　安裝說明
遊戲製作：Eric Hu
==================================================

一、資料夾裡有什麼
--------------------------------------------------
  index.html     遊戲本體（打開網站時第一個讀到的檔案）
  games\         遊樂場「對戰遊戲區」的 6 款遊戲
                   hockey  霓虹冰球
                   f1rush  極速F1
                   army    萌萌軍團大衝鋒
                   cube    萌萌方塊消消樂（裡面的 three.min.js 不能刪）
                   zombie  屍潮防線
                   maze    萌萌迷宮大冒險
  music\         背景音樂 12 首（已壓縮成較小的檔案，出處寫在遊戲「聲明」裡）
  安裝說明.txt   就是這份

  ※ 三個東西（index.html、games、music）一定要放在同一層，不能拆開。
  ※ 不要直接雙擊 index.html 來玩：瀏覽器會擋掉對戰遊戲和雙人冰球，
    請照下面的方法放到網站上，用網址打開。

二、方法 A：Netlify 拖曳上傳（最簡單，約 3 分鐘）
--------------------------------------------------
  1. 用電腦打開 https://app.netlify.com ，登入（可以用 GitHub 帳號登入）。
  2. 左邊選「Sites」（網站），往下找到「把資料夾拖到這裡」的虛線方框
     （網址：https://app.netlify.com/drop 也可以）。
  3. 把整個「製作大亨」資料夾拖進方框，放開滑鼠。
  4. 等它上傳完（約 20MB，網路慢的話要 1～2 分鐘），
     畫面會出現一個網址，例如 https://xxxx-xxxx.netlify.app 。
  5. 點那個網址就能玩。手機打開同一個網址也可以玩。
  6. 想改好記的名字：網站頁面 →「Site configuration」→「Change site name」。
  7. 以後要更新版本：網站頁面 →「Deploys」→ 把新的資料夾再拖進去即可。

三、方法 B：GitHub ＋ Render（跟你其他遊戲一樣的放法）
--------------------------------------------------
  1. 在 GitHub 建立新的儲存庫，例如 tycoon-game（公開或私人都可以）。
  2. 進入儲存庫 →「Add file」→「Upload files」，
     把「製作大亨」資料夾「裡面」的東西（index.html、games、music、安裝說明.txt）
     全部拖進去（不要多包一層資料夾），按「Commit changes」。
     ※ 如果網頁一次傳不完，可以分兩次：先傳 index.html 和 games，再傳 music。
  3. 打開 https://dashboard.render.com →「New +」→ 選「Static Site」（靜態網站）。
  4. 選剛剛的 tycoon-game 儲存庫。
  5. 設定：
       Build Command（建置指令）：留空白
       Publish Directory（發布資料夾）：輸入一個點「.」
  6. 按「Create Static Site」，等 1～2 分鐘，上方會出現 https://xxxx.onrender.com 網址。
  7. 以後要更新：把新檔案上傳到 GitHub 蓋過舊的，Render 會自動更新。
  ※ 這個遊戲不需要伺服器程式，用「Static Site」就好（免費、不會休眠）。

四、測試前要知道的事
--------------------------------------------------
  ．進度存在玩家自己的瀏覽器裡。換手機、換瀏覽器或清除瀏覽器資料就會重來。
  ．放到自己網站後，排行榜只會顯示這台裝置的紀錄
    （跨裝置的排行榜要另外架伺服器，之後可以再加）。
  ．手機瀏覽器規定：要先點一下畫面，背景音樂和音效才會出來。
  ．背景音樂可以在首頁「⚙️ 設定」裡開關。
  ．雙人合作：首頁按「雙人合作」，同一台裝置兩個人一起玩
    （手機：左半邊 1P、右半邊 2P；電腦：1P 用 WASD、2P 用方向鍵）。
  ．對戰遊戲：地圖左上角「🎡 遊樂場」→ 往下找「⚔️ 對戰遊戲區」。
    單人每場 50 元，雙人對戰每場 100 元，只是玩樂不會賺錢。
  ．雙人即時對戰：1P 是大畫面、2P 是右下角小視窗，兩人同時玩同一關。
    小視窗上方的粉紅色標題列：長按就能拖曳位置；「大小」可以切換三種大小；
    「⇄ 換大畫面」可以讓 2P 變成大畫面。
    電腦同一個鍵盤：1P 用 W A S D＋空白鍵（F、G 也可以），2P 用方向鍵＋Enter／右 Shift。
    手機：兩人各自點、拖自己的畫面。
    霓虹冰球是兩人在同一張球桌上直接對打。

五、遇到問題
--------------------------------------------------
  ．打開是空白：確認 index.html 跟 games、music 在同一層，並且是用網址打開。
  ．沒有聲音：先點一下畫面；再檢查手機是否在靜音模式。
  ．畫面很卡：到「⚙️ 設定」把畫質改成「省電」。
