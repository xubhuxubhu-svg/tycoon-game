製作大亨　第 1 系列「飲食與料理」　版本 1.2（多人連線版）　安裝說明
遊戲製作：Eric Hu
==================================================

一、資料夾裡有什麼
--------------------------------------------------
  index.html     遊戲本體
  server.js      連線伺服器程式（負責：提供網頁、雙人連線合作、對戰連線）
  package.json   告訴 Render 要安裝什麼、怎麼啟動（不用改）
  games\         遊樂場「對戰遊戲區」的 6 款遊戲
                   hockey  霓虹冰球（已加入不同裝置連線對打）
                   f1rush  極速F1（用遊戲內建的連線賽車）
                   army    萌萌軍團大衝鋒
                   cube    萌萌方塊消消樂（裡面的 three.min.js 不能刪）
                   zombie  屍潮防線
                   maze    萌萌迷宮大冒險
  music\         背景音樂 12 首（出處寫在遊戲「聲明」裡）
  安裝說明.txt   就是這份

  ※ 全部東西要放在同一層，不能拆開。
  ※ 這一版有「不同裝置連線」，一定要用 Render 的「Web Service（網頁服務）」，
    不能再用「Static Site（靜態網站）」或 Netlify 拖曳上傳（那些沒有伺服器，無法連線）。

二、上傳到 GitHub
--------------------------------------------------
  1. 打開 https://github.com ，登入。
  2. 如果已經有之前建立的 tycoon-game 儲存庫，直接進去；
     沒有的話：右上角「＋」→「New repository」（新增儲存庫），
     名稱輸入 tycoon-game，按最下面的「Create repository」（建立）。
  3. 在儲存庫頁面按「Add file」（新增檔案）→「Upload files」（上傳檔案）。
  4. 把這個資料夾「裡面」的東西全部拖進去：
       index.html、server.js、package.json、games、music、安裝說明.txt
     ※ 不要多包一層資料夾；如果網頁一次傳不完，可以分兩次：
       第一次 index.html、server.js、package.json、games；第二次 music。
     ※ 舊版的檔案會被同名的新檔案蓋過，不用先刪。
  5. 拉到下面按綠色的「Commit changes」（確認送出）。

三、在 Render 建立「網頁服務」
--------------------------------------------------
  1. 打開 https://dashboard.render.com ，登入（可以用 GitHub 帳號登入）。
  2. 右上角「New +」（新增）→ 選「Web Service」（網頁服務）。
  3. 選「Git Provider」（從 GitHub 匯入），在清單裡找到 tycoon-game，按「Connect」（連接）。
     （找不到的話，按「Configure account」把這個儲存庫的權限打開。）
  4. 設定欄位：
       Name（名稱）              ：tycoon-game（會變成網址的一部分，可自己取）
       Language / Runtime（語言） ：Node
       Branch（分支）            ：main
       Root Directory（根目錄）  ：留空白
       Build Command（建置指令） ：npm install
       Start Command（啟動指令） ：npm start
       Instance Type（方案）     ：Free（免費）
  5. 按最下面的「Deploy Web Service」（部署）。
  6. 等畫面下方的紀錄出現「製作大亨 伺服器啟動於連接埠 …」以及「Your service is live」
     （服務已上線），左上方會有 https://tycoon-game-xxxx.onrender.com 這樣的網址。
  7. 點網址就能玩；手機、平板、別台電腦打開同一個網址也可以。

  ※ 如果你之前已經用「Static Site」建立過：Render 沒辦法直接把它改成網頁服務，
    請照上面步驟新建一個「Web Service」（可以用同一個儲存庫），
    確定新的能玩之後，再到舊的靜態網站 →「Settings」（設定）→ 最下面「Delete」（刪除）。
  ※ 免費的網頁服務一段時間沒人玩（大約 15 分鐘）會自動休眠，
    下一次打開網址要等大約 1 分鐘讓它醒來，這是正常的。

四、以後要更新版本
--------------------------------------------------
  把新版檔案上傳到 GitHub 的同一個儲存庫（同名檔案直接蓋過）→「Commit changes」。
  Render 會自動重新部署，約 1～3 分鐘後重新整理網頁就是新版本。
  玩家的進度存在各自的瀏覽器裡，更新版本不會不見。

五、怎麼用不同裝置一起玩
--------------------------------------------------
  【雙人合作（2 人）】和【多人合作（3～4 人）】
  1. 房主：首頁按「👥 雙人合作」或「👨‍👩‍👧‍👦 多人合作」→「🏠 建立房間」，
     畫面會出現 4 位數房號（遊戲中左上角也會一直顯示房號和每位玩家的狀態）。
  2. 其他人：打開同一個網址 → 首頁按同一個按鈕 → 輸入房號 →「🚪 加入」。
  3. 大家在「房主的地圖」上一起搬運、加工、開店；錢是共用的。
     每個角色頭上都會顯示玩家的暱稱，每個人用自己的裝置操作：
       手機：手指在畫面上拖曳移動；電腦：W A S D 或方向鍵。
  4. 加入別人的房間時，經營的是房主的地圖，不會影響自己的存檔。
  5. 有人不小心登出（關掉網頁、按 🏠、網路斷掉）：
       ．他的角色會消失，左上角顯示「○○ 已登出」。
       ．他回首頁、重新輸入同一個房號，就會回到原本的位置，角色重新出現。
       ．房主登出時，其他人的地圖會先暫停，等房主輸入房號回來就繼續。
       ．房間裡都沒人超過 30 分鐘，房間才會關閉。
  6. 固定房號：房主第一次建立房間時會得到一組「固定房號」，以後每次建立房間都是同一個號碼，
     朋友記住這個號碼就好（在「雙人合作／多人合作」視窗裡看得到；想換可以按「🔄 換新號碼」）。
  7. 隔天想接續進度：房主用「同一台裝置、同一個瀏覽器」打開遊戲 →「建立房間」，
     地圖就是昨天的進度；朋友輸入同一個固定房號加入即可。地圖存在房主那邊，所以房主一定要在線上。
  8. 任何一人按「⏸️ 暫停」，大家都會一起暫停。
  9. 獎金小遊戲跳出來時大家都看得到，誰先按「搶先玩」就是誰玩。

  【對戰（6 款遊戲）】
  1. 在房間裡，任何一人按「🎡 遊樂場」→「⚔️ 對戰遊戲區」→ 選遊戲和關卡 →「邀請對戰」。
  2. 其他人的裝置會跳出邀請，可以「應戰」或「不參加」；全部回覆後自動開始
     （發邀請的人也可以按「先開始」）。
  3. 每位參加的玩家從共同現金扣 50 元（雙人就是 100 元），只是玩樂不會賺錢。
  4. 雙人合作：右下角小視窗是對手的即時畫面（長按標題拖曳、「大小」可切換）。
     多人合作：人比較多，每個人只看自己的遊戲畫面；結束後公布排名，第 1 名有皇冠和特效。
  5. 霓虹冰球：2 人時是同一張球桌即時對打；3～4 人時每人各自對電腦，依比分排名。
     極速F1：大家在同一條賽道一起比賽，空位由電腦車手補滿。
  6. 一個人先完成後，其他人還有 45 秒可以完成。

  【手機操作】
  ．極速F1：左下角的左、右鍵加大了；也可以「傾斜手機」來轉彎（按「📱 傾斜」可以開關）。
    蘋果手機第一次會詢問是否允許使用動作感應，請按「允許」。
  ．萌萌迷宮大冒險：畫面左下角有「上、下、左、右」方向鍵。
  ．屍潮防線、萌萌軍團大衝鋒：這兩款是自動往前跑的遊戲，只需要左右移動，
    所以手機畫面左下角是加大的「左、右」鍵。

  【排行榜】
  ．首頁「🏆 排行」最上面是你自己的進度；下面是你和一起連線玩過的玩家（最多保存 10 位），
    每個人旁邊有最後登入日期。

  【修改暱稱】
  ．首頁「⚙️ 設定」→ 在暱稱欄輸入新名字 → 按「修改」，出現「修改成功」就好了，不用重置進度。

六、測試前要知道的事
--------------------------------------------------
  ．進度存在玩家自己的瀏覽器裡。換手機、換瀏覽器或清除瀏覽器資料就會重來。
  ．手機瀏覽器規定：要先點一下畫面，背景音樂和音效才會出來。背景音樂可以在「⚙️ 設定」開關。
  ．同一台裝置兩人一起玩的方式也還在：「👥 雙人合作」下方的「📱 同一台裝置一起玩」。
  ．直接雙擊 index.html 也能單人玩，但「不同裝置連線」一定要用 Render 網址打開。

七、遇到問題
--------------------------------------------------
  ．Render 部署失敗：確認 package.json 和 server.js 有上傳、而且跟 index.html 在同一層；
    建置指令是 npm install、啟動指令是 npm start。
  ．按「建立房間」顯示連不上：伺服器可能剛睡醒，等 30 秒～1 分鐘再按一次。
  ．輸入房號說找不到房間：確認兩人打開的是「同一個網址」，而且房主還在地圖裡沒有離開。
  ．對戰小視窗一直顯示「等待對手畫面」：對方網路太慢，或對方還在載入遊戲，稍等一下。
  ．畫面很卡：到「⚙️ 設定」把畫質改成「省電」。
